# Kit Roteiro Pronto para TikTok Shop (produto de marca própria, fora da BSM Digital)

## O que é
Infoproduto para afiliados que divulgam produtos de terceiros no TikTok Shop. Vende modelagem em vez de aula: a pessoa pega um vídeo real que já está vendendo, extrai a estrutura dele com um comando de IA (o Modelador) e recebe um roteiro original para o próprio produto.

## Diferencial competitivo (usar isso na copy de vendas)
Já existem muitos pacotes de "roteiros prontos para TikTok Shop" no mercado, vendidos como bancos de frases genéricas. O diferencial deste produto não é a quantidade de roteiros prontos, é o método de modelar a partir de um vídeo real que já provou que vende. Isso é mais difícil de copiar do que um banco de frases e não fica desatualizado, porque não depende de uma lista fixa de frases: a pessoa sempre modela em cima do que está vendendo agora. Esse é o argumento central para diferenciar de concorrentes que vendem só volume de roteiros.

## Público-alvo
Afiliados que divulgam produtos de terceiros no TikTok Shop (não são donos de loja própria, não são o público da BSM Digital, que fala com especialistas e mentores).

## Regra de linguagem para exemplos de roteiro (TikTok Shop)
- O carrinho de compra do TikTok Shop é laranja, nunca chamar de "carrinho amarelo".
- Não usar "link na vitrine". Usar "é só clicar aqui embaixo no carrinho" como chamada para ação padrão.
